# 케어센터 발행 데스크 사양 (2026-08-02 재설계)

v1 마이가디언의 발행 도구를 실물로 확인하고(사용자 제공 화면 4장 + 기존 발행물 데이터),
v2 데스크를 그 수준으로 다시 짓는다. 종전 v2 데스크의 뉴스 수집·후보·집필 지시문은 폐기한다.

## 폐기

- **뉴스 수집·후보 목록** (STEP 1) — 사용자가 시사에 밝아 후보 목록이 실익이 없다.
  `pipeline/collect_news.py` 호출 안내, `data/care/desk/candidates.json` 읽기, 관련 UI 전부 삭제.
- **집필 지시문 복사** (STEP 3) — 클로드에게 줄 지시서를 복사하는 기능이었으나
  ① 화면에 용도 설명이 없어 사용자가 무엇인지 알지 못했고 ② 내용이 낡았다(터미널 명령·
  publish_care_issue.py 검증 등, 발행 버튼 도입으로 사라진 단계). AI 추천이 쓸모를 대신한다.

## 칼럼 구조 (2026-08-02 사용자 확정)

| 채널 | 칼럼 수 | 주제 | 성격 |
|---|---|---|---|
| 주간 안창민 | 3 | 1 정치·사회·시사 / 2 경제·AI·IT / 3 보험 | 최신. 분량 적게 |
| 월간 안창민 | 3 | 자유 | 심도 있고 방대하게 |

종전 주간 4칸(시사·경제·교양·보험)에서 **교양을 빼고 3칸으로** 바꾼다.

**분량 기준** (기존 발행물 실측)
- 주간 칼럼 본문: 1,700~2,800자
- 월간 칼럼 본문: 6,800~10,800자 (v1 입력창 안내는 "8,000~10,000자")
- 요약: 150~200자 (서재 카드·스와이프 뷰용)

## 이미지 (2026-08-02 사용자 확정)

- **칼럼 하나당 이미지 1장 + 대표(표지) 이미지 1장.** 주간·월간 모두 = 호당 4장.
  (v1은 칼럼당 2장이었으나 사용자 지시에 따라 1장으로 통일)
- 수급 경로 3갈래를 화면에서 고를 수 있어야 한다:
  1. **AI 창작** — 코덱스에 프롬프트를 넘겨 생성
  2. **기존 이미지 AI 변환** — 올린 사진을 일러스트 등으로 변환
  3. **그냥 사용** — 올린 사진을 그대로
- 저장은 기존 `/media/upload` 경로 재사용, 기사 JSON의 `이미지` 필드에 경로 기록
  (필드는 이미 존재 — 데이터 구조 변경 불필요).

## 화면 흐름

```
호 목록 (표지 카드 + 편집중/발행됨 배지)
  └ 새 호 만들기 (연도·월 또는 주차 선택)
      └ 호 편집
          ├ 발행 준비 상태 체크리스트 (n/m — 뭐가 비었는지)
          ├ 표지 이미지
          ├ 편집장의 말
          ├ 칼럼 1~3 — 각 칼럼마다:
          │    · AI 주제 추천 / AI 제목 다듬기 (칼럼별 버튼)
          │    · 제목 · 부제 · 요약(150~200자) · 본문(마크다운) · 이미지 1장
          ├ 미리보기 — 실제 지면 그대로 렌더
          └ 발행하기 → 발행 후 카톡 문구 사용 가능
```

- **미리보기**는 고객이 볼 지면(care/issue.html)과 같은 조판으로 띄운다. 발행 전 검토용.
- **카톡 문구**는 발행이 끝난 뒤에만 활성화된다 (미발행 호의 링크를 보내는 사고 방지).
- 발행 준비 상태는 v1처럼 항목별 충족/미충족과 글자 수를 함께 보여준다.

## AI 기능

- 서버 `/ai/title` 확장 또는 신규 엔드포인트로 처리. Claude 중계는 이미 구축돼 있다.
- **주제 추천**: 채널·칼럼 성격을 주면 이번 호 주제 후보를 제안.
- **제목 다듬기**: 기존 기능 유지, 칼럼별로 배치.
- 본문 생성은 데스크에서 강제하지 않는다 — 8,000~10,000자에 근거 교차확인이 필요한 작업이라
  클로드코드에서 쓰고 붙여넣는 경로를 열어 둔다(붙여넣기 칸 + 글자 수 표시).

## 본문 조판 문법 (기존 발행물에서 확인)

마크다운. 실제로 쓰이는 것:
- `##` 대제목, `###` 소제목
- `> **68%** — 설명` 형태의 **숫자 인용구** (지면에서 강조 블록으로 렌더)
- 표 (`| 구분 | ... |`)
- 리스트, 굵게
- 본문 중간 이미지

지면(care/issue.html)이 이 문법을 전부 렌더해야 한다.
