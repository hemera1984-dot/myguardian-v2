### 고객 데이터 서버화 방침 전환 (2026-08-02 사용자 결정)
- 종전의 "신한라이프 규정 확인 통과 후 착공" 게이트를 폐기. 사용자 판단.
- 대신 **종단간 암호화**를 전제로 한다. 서버는 암호문만 보관(AES-GCM 256, WebCrypto,
  의존성 0). 열쇠는 잠금문구에서 PBKDF2 파생, 서버는 잠금문구·열쇠를 받지 않는다.
- 이유: 마스킹만으로는 폰에서 고객관리를 쓸 수 없다(전화·식별 불가). 암호화는 서버 쪽
  비식별을 마스킹보다 강하게 달성하면서 FC 화면에서는 원문을 그대로 쓴다.
- 미결: 잠금문구 분실 시 복구 불가 — 로컬 폴더 내보내기를 백업 경로로 유지할 것.
- 착공 전 필요한 사용자 액션은 하나뿐: 예전 PC에서 고객 데이터 폴더 복사(mg-clients-fc01~03).
